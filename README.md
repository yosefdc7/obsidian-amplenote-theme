# Amplenote Theme for Obsidian

A clean, minimalist, high-velocity Amplenote-inspired theme for Obsidian desktop and mobile.

## Features

- **Amplenote Typography & Hierarchy**: Refined typographic scale with italic H2, bold H3, and proportional outliner spacing.
- **Reading Comfort**: Generous 0.5-inch reading margins on both desktop and mobile viewports.
- **Task Styling**: Crisp completed-task strikethrough and styling matching Amplenote workflows.
- **Minimalist Foundations**: Built on top of Minimal v9.0.2 for rock-solid stability and responsiveness.

## Installation

### Via BRAT (Recommended for Mobile & Desktop Sync)
1. Install and enable the **Obsidian42 - BRAT** community plugin.
2. In BRAT settings, click **Add a theme for testing**.
3. Enter `yosefdc7/obsidian-amplenote-theme`.
4. In Obsidian, go to **Settings > Appearance > Themes** and select **Amplenote**.

### Manual Installation
1. Download `theme.css` and `manifest.json` from the latest release.
2. Copy them into your vault at `.obsidian/themes/Amplenote/`.
3. In Obsidian, go to **Settings > Appearance > Themes** and select **Amplenote**.
